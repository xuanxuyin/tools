### 方法论沉淀（以后照此判断）

1. **收录 ≠ 排名**：`site:` 有条目 = 上牌桌；排名分要 2~8 周攒。新站第 2~3 天不在前 100 名是标准状态，连黄灯都不算
2. 验证三连（目的不同，搜法不同）：
   - 收录了没 → `site:tintbrew.com`
   - 自己的页能不能被找到 → 搜 `tintbrew black and white`（带品牌词；**绝不能写 `-tintbrew`**，减号 = 排除自己，永远搜不到）
   - 关键词真实排名 → 只搜裸词 + 无痕 + 美国代理
3. 手工搜的两个系统性偏差：国内直连 ≠ 美区 SERP；手工搜到我们比 GSC 出现曝光**晚 1~2 周**（Google 先在 Performance 里给曝光试量）
4. GSC 中文界面对照：Performance = **效果**（报表名"搜索结果"）；Queries = **查询**；Impressions = **展示次数**；Clicks = **点击次数**；Average position = **平均排名**。完整报表走**左侧菜单「效果」**，概述页里的效果卡片只是摘要
5. Request indexing 正确姿势：GSC 顶部搜索框粘**完整 URL**（`https://tintbrew.com/xxx/`，带协议头 + 尾斜杠，不带 www）；只输路径会报"无效网址"。每 URL 只请求一次
6. 考察期纪律：**不改页面、不重复请求索引**；唯一能主动加速排名的杠杆 = 外链（目录站）
