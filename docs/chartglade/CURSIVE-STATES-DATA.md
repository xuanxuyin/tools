# #16 诱饵页 50 州 cursive 立法数据档

> 调研完成 2026-10-12【实勘 agent 三源交叉（EdWeek 2024-11 / MyCursive 2025-05 / NSEA 2026-03）+ 州官网/权威媒体逐项核对】。
> 页面 = `/states-that-require-cursive/`（外链优先非流量页，PLAN #16）。数据准确度是命根子：竞品 MyCursive 2025-05 版含 2 处硬错误 + 1 漏计，我们的超越点。

## 分档口径（页面核心差异化）

- **A 档 = 州成文法明文要求（19 州）**
- **B 档 = 州学习标准/州教育董事会要求，无专门法条（8 州）**
- **C 档 = 无要求/未立法（23 州，截至 2026-10 未见）**

A+B = 27 州。各追踪器打架根源 = 法条 vs 标准混数（Wikipedia 2024-07 的"25 州"直接引自 MyCursive；EdWeek 2024-11 报 24 漏标准州；NSEA 2026-03 的"27"与 A+B 吻合）。

## 竞品错误清单（页面可直说的差异）

1. **Maine**：MyCursive 误列为 2025 新增要求州——实际 LD 78 (2025) 被改成"DOE 草书教学数据调研" resolve，只是摸底
2. **Indiana**：MyCursive 误计为要求州——2018 法仅"允许"开设，2023 法仅要求向 DOE 报告开设情况
3. **Idaho**：MyCursive 漏计——SB 1044 (2025) 2025-07-01 生效，5 年级末读写双达标
