## 一、起卦数学（纯函数，引擎层）

```
输入：三个数 A、B、C（数字大小不限，用户默念问题后报出/掷出）
上卦 = A mod 8，余 0 按 8   → 先天八卦数
下卦 = B mod 8，余 0 按 8   → 先天八卦数
动爻 = C mod 6，余 0 按 6   → 从下往上数第 1~6 爻
本卦 = (上卦, 下卦) 查六十四卦表
变卦 = 本卦六爻中第"动爻"位阴阳反转 → 重新查表（自动推导，无需人工维护）
```

- 爻的阴阳编码（每卦自下而上 6 爻，下卦=1~3 爻，上卦=4~6 爻）：
  乾☰[1,1,1] 兑☱[1,1,0] 离☲[1,0,1] 震☳[1,0,0] 巽☴[0,1,1] 坎☵[0,1,0] 艮☶[0,0,1] 坤☷[0,0,0]
- 验算样例【实勘·多源一致】：34 mod 8 余 2=兑；43 mod 8 余 3=离；43 mod 6 余 1=初爻动。乾卦初爻动→变姤（[1,1,1,1,1,1] 翻第 1 爻→巽下乾上）✓ 与传世占例一致
- 我们的工具永远只有**一个动爻**（C 只出一个数）→ 恰好落在朱熹占法最清晰的分支：**一爻变，以本卦变爻爻辞为主**

## 四、解卦框架（输出结构）

一次起卦输出四层（对应 👤 给的第三步，检索确认解读惯例）：

1. **本卦 = 现状**：卦名 + 卦辞改写——事情此刻的基本状态
2. **动爻 = 关键变量**：自下而上数到第 m 爻，该爻爻辞改写——变化的那个点（一爻变时以它为主）
3. **变卦 = 走向**：动爻阴阳反转后的卦——如果顺着本卦走，事情往哪去
4. **行动建议**：我们的 house voice 一条可执行下一步（对齐签库六件套的行动层）

- 爻题名规则：阳爻称九（初九/九二/…/上九）、阴爻称六（初六/…/上六）；乾另有用九、坤另有用六（产品层可并入"全阳/全阴"特判，v1 可不做）
- **砍掉的深水区**（复杂度护栏，产品不进）：互卦、体用生克、五行旺衰、多爻变占法（我们恒一爻变，天然规避朱熹七条占变的复杂分支）
